# คู่มือผู้ดูแลระบบ (Admin)

แอดมิน **ทำได้ทุกอย่างแทนทุกตำแหน่ง** + งานเฉพาะ: จัดการผู้ใช้ จัดการวัสดุ
ย้ายงาน ลบ/กู้คืนใบงาน และแก้กรณีที่พนักงานทำเองไม่ได้
อ่านเรื่องพื้นฐานได้ที่ [README.md](README.md) — คู่มือแต่ละตำแหน่งใช้ประกอบเวลาแก้งานแทน

## เมนูที่คุณใช้ได้

ทุกเมนู: หน้าหลัก · สร้างใบงาน · งานทั้งหมด · สรุปงานรายวัน · ตรวจเงิน · โปรไฟล์ · **ตั้งค่า**
(**จ่ายรวม** ไม่อยู่ในเมนูข้าง — เข้าจากปุ่ม 💳 บนหน้าหลัก หรือลิงก์ในหน้าตรวจเงิน)

---

## 1. จัดการผู้ใช้ (ตั้งค่า > ผู้ใช้)

| งาน | วิธีทำ | หมายเหตุ |
|---|---|---|
| สร้างพนักงานใหม่ | กรอก username (ตัวพิมพ์เล็ก a-z 0-9 _), รหัสผ่าน, ชื่อที่แสดง, ตำแหน่ง | บอก username+รหัสให้พนักงานโดยตรง |
| เปลี่ยนตำแหน่ง | เลือกตำแหน่งใหม่ | พนักงานถูกบังคับ login ใหม่ทันที · **เปลี่ยนตำแหน่งตัวเองออกจาก admin ไม่ได้** |
| ปิดบัญชี (พนักงานลาออก) | ปิด "ใช้งาน" | ถูกดีดออกจากระบบทันทีทุกเครื่อง · **ปิดบัญชีตัวเองไม่ได้** — อย่าลบ ให้ปิดแทน ประวัติงานจะยังอยู่ |
| ตั้งรหัสผ่านใหม่ (ลืมรหัส) | Reset password | หลุดจากระบบทุกเครื่อง ต้อง login ใหม่ · ใช้เฉพาะกรณี**ลืมรหัส** — ถ้าแค่อยากเปลี่ยน พนักงานเปลี่ยนเองได้ที่หน้า**โปรไฟล์** (ต้องรู้รหัสปัจจุบัน) |

ตำแหน่งที่มี: **seller** (ฝ่ายขาย) · **graphic** (กราฟิก — รวมพิมพ์ FUJI) · **production** (ฝ่ายผลิต) ·
**finance** (การเงิน — อ่านได้หมด แก้ได้เฉพาะเงิน) · **admin**

> ให้ตำแหน่งตามหน้าที่จริงเท่านั้น — โดยเฉพาะ admin กับ finance ให้เท่าที่จำเป็น

## 2. จัดการราคากลาง (ตั้งค่า > ราคากลาง)

ราคากลางต่อประเภทงาน + ตัวเลือก (เช่น ไวนิล+ตาไก่) — ระบบใช้เทียบกับราคาขายจริง
ของฝ่ายขายอัตโนมัติ ถ้าขายต่ำกว่าเกณฑ์จะติดธงแดงที่หน้าตรวจเงิน

- เพิ่ม/แก้ด้วยปุ่ม **+ เพิ่มราคากลาง** ในหน้าตั้งค่า
- **อัปเดตทุกครั้งที่ต้นทุนหรือนโยบายราคาเปลี่ยน** — ราคากลางที่ล้าสมัยทำให้ธงแดงมั่ว
  (งานปกติโดนธง / งานกดราคาหลุดรอด) แล้วฝ่ายการเงินจะตรวจเพี้ยนทั้งระบบ
- ถ้ายังไม่เคยตั้งเลย มี seed script ให้ (`scripts/seed-rate-cards.ts` — งานฝั่งเทคนิค)

## 3. จัดการวัสดุ (ตั้งค่า > วัสดุ)

รายการวัสดุที่คนพิมพ์เลือกตอนบันทึกการพิมพ์:

- เพิ่ม/แก้: หมวด (ไวนิล/สติกเกอร์), ยี่ห้อ, ป้ายชื่อ, **หน้ากว้างม้วนที่มีจริง**, ต้นทุนต่อตารางเมตร (ถ้ารู้)
- วัสดุเลิกใช้ → ปิด active (หายจาก dropdown แต่ประวัติเก่ายังอยู่) — อย่าลบ
- หน้ากว้างม้วนต้องตรงกับม้วนที่ซื้อจริง ไม่งั้นคนพิมพ์เลือกไม่ได้/เลือกผิด แล้วตัวเลขเศษจะเพี้ยนทั้งระบบ

## 4. แก้งานแทนพนักงาน (กรณีที่พบบ่อย)

| พนักงานแจ้งว่า | สิ่งที่ต้องทำ |
|---|---|
| กราฟิก/คนพิมพ์รับงานผิดคน หรือลาป่วยงานค้าง | เปิดใบงาน → ย้ายงาน (reassign) ให้คนใหม่ · งานออกแบบที่ยัง "กำลังออกแบบ" กราฟิกใช้ปุ่ม **🔄 ส่งต่องาน** กันเองได้ ไม่ต้องผ่านคุณ |
| คนพิมพ์กรอกบันทึกการพิมพ์ผิด (วัสดุ/ความยาว) | ทีมเครื่องนั้นแก้เองได้ที่ปุ่ม **✏️ แก้บันทึก** ในใบงาน (แอดมินแก้ได้ทุกรายการ) — บังคับใส่เหตุผล ทุกการแก้ลง audit ก่อน/หลัง |
| ฝ่ายขายคอนเฟิร์มผิด / ลูกค้าเปลี่ยนใจหลังคอนเฟิร์ม | เปิดใบงาน → ปุ่ม **🔀 ปรับสถานะ (admin)** เลือกสถานะใหม่ + ใส่เหตุผล (บังคับ ลงประวัติเสมอ) — ข้ามขั้นได้ทุกสถานะ ใช้เท่าที่จำเป็น |
| ต้องแก้ใบงานหลังคอนเฟิร์ม (ขนาด/รายการ) | แอดมินแก้ได้ทุกสถานะ — แก้รายการงานแล้วยอดเงินคำนวณใหม่อัตโนมัติ |
| เปิดใบงานผิด ต้องลบ | ลบใบงาน (soft delete — กู้คืนได้ทีหลัง) |
| บันทึกงานเสียผิดรายการ | ยกเลิก (void) รายการงานเสียนั้น แล้วให้บันทึกใหม่ |
| กรอกยอดเงินผิด | ปรับยอดเงินในใบงาน (ใส่เหตุผล — ลง audit เสมอ) |
| วัสดุไม่มีใน dropdown | เพิ่มที่ ตั้งค่า > วัสดุ |

## 5. สิ่งที่ควรรู้เกี่ยวกับระบบ

- **ทุก action ลง audit** — รวมของแอดมินเอง ประวัติดูได้ท้ายใบงาน + หน้าตรวจเงิน
- **ยอดรวมเงินเป็นของระบบ** — คำนวณจากรายการงานฝั่งเซิร์ฟเวอร์เสมอ ไม่มีใครพิมพ์ทับได้ (รวมแอดมิน) ต้องการเปลี่ยนยอด = แก้รายการงานหรือส่วนลด
- **ลบ = ซ่อน** — ใบงานที่ลบกู้คืนได้ ไม่มีอะไรหายถาวรจากหน้าจอ
- ใบเสร็จลูกค้าเปิดผ่านลิงก์ QR ได้โดยไม่ต้อง login — เป็นหน้าสาธารณะที่ตั้งใจให้เป็นแบบนั้น
- เรื่องเชิงเทคนิค (deploy, schema, Cloud Functions) ดู `SCHEMA.md` และ `docs/` ในโปรเจกต์ — คู่มือชุดนี้สำหรับผู้ใช้งานเท่านั้น
