กติกากลาง: ทุกการกระทำถูกบันทึกในประวัติใบงาน · คุยข้ามฝ่ายผ่านช่องคอมเมนต์ในใบงาน · อย่าแชร์รหัสผ่าน

1รับงานพิมพ์

  1. ดูคิวกลาง — งานป้าย ด่วน! ทำก่อน และดูวันนัดรับงานประกอบการจัดคิว
  2. เปิดใบงาน ดูรายละเอียด: ประเภท ขนาด ตัวเลือก (ตาไก่/พับขอบ) จำนวน + รูปแบบที่คอนเฟิร์มแล้ว (หัวข้อ "ฝ่ายกราฟิก › รูปที่ออกแบบ" — พิมพ์ตามแบบนี้เท่านั้น)
  3. ที่หัวข้อ งานพิมพ์แต่ละเครื่อง กด รับงานนี้ ตรงเครื่องที่คุณจะทำ

2พิมพ์และบันทึกการพิมพ์

พิมพ์เสร็จแล้ว เปิดใบงานทำ 2 อย่าง (บังคับทั้งคู่):

2.1 แนบรูปงานพิมพ์ (บังคับ)

ถ่ายรูปงานที่พิมพ์จริง อัปโหลดเข้าใบงาน

2.2 กรอกบันทึกการพิมพ์ ต่อรายการงาน

ช่องกรอกอะไร
วัสดุเลือกจากรายการ (เช่น ดีรุยเซ่น หลังขาว, HP)
หลังขาว/ดำ/เทาเฉพาะงานไวนิล
หน้ากว้างม้วนเลือกตามม้วนที่ใช้จริง (เช่น 1.32 / 1.62 / 3.22 ม.)
ความยาวที่ใช้ (เมตร)วัดจากม้วนจริง รวมส่วนที่เผื่อ/เล็ม — ไม่ใช่ขนาดชิ้นงาน
จำนวนพิมพ์จริงระบบใส่ให้เท่าจำนวนสั่ง แก้ได้ถ้าพิมพ์เผื่อ
พิมพ์รวมม้วนจัดวางหลายรายการบนม้วนเดียวกัน ให้ผูกเป็นชุดเดียวกัน — ระบบจะเฉลี่ยวัสดุให้ถูก

บันทึกครบแล้วงานย่อยเครื่องนั้น = เสร็จ

⚠️ กรอกตามจริงเสมอ — ระบบคำนวณพื้นที่ที่ใช้เทียบกับพื้นที่ที่ขาย ออกมาเป็นเปอร์เซ็นต์เศษวัสดุอัตโนมัติ ถ้าเกินเกณฑ์ (ประมาณ 30% เตือน / 50% ธงแดง) จะขึ้นรายงานที่ฝ่ายการเงิน — เศษเยอะเพราะงานชิ้นเล็กจัดวางไม่ลงตัวเป็นเรื่องปกติ อธิบายได้ แต่ตัวเลขที่กรอกมั่วจะตรวจเจอตอนกระทบยอดม้วนวัสดุ

3กรอกผิด แก้ยังไง

แก้ได้เองในใบงาน:

  1. เปิดใบงาน → หัวข้อ บันทึกการพิมพ์ที่บันทึกแล้ว
  2. กด ✏️ แก้บันทึก ที่รายการที่ผิด → แก้วัสดุ/ม้วน/ความยาว/จำนวนให้ถูก
  3. ใส่เหตุผลที่แก้ (บังคับ เช่น "กรอกความยาวผิด วัดใหม่ได้ 4.2 ม.") → กด 💾 บันทึกการแก้
  • แก้ได้เฉพาะรายการของทีมเครื่องตัวเอง (งาน FUJI ทีมกราฟิกแก้ / เครื่องอื่นทีมผลิตแก้)
  • ระบบเก็บค่าก่อน/หลังแก้ + เหตุผล ลงประวัติใบงานเสมอ — ชื่อผู้พิมพ์เดิมไม่เปลี่ยน
  • เศษวัสดุคำนวณใหม่อัตโนมัติจากค่าที่แก้

4บันทึกงานเสีย

พิมพ์เสีย ตัดเสีย เครื่องมีปัญหา สีเพี้ยน วัสดุมีตำหนิ → กด งานเสีย ในใบงาน:

  1. เลือกเหตุผล (เลือก "อื่นๆ" ต้องพิมพ์รายละเอียด)
  2. เลือกวัสดุ หน้ากว้างม้วน ความยาวที่เสีย จำนวนที่เสีย
  3. บันทึก — แล้วพิมพ์ใหม่ + บันทึกการพิมพ์รอบใหม่ตามปกติ

การบันทึกงานเสียทำจากในใบงานเท่านั้น — วัสดุที่เสียโดยไม่เกี่ยวกับใบงานไหนเลย (เช่น ทดสอบเครื่อง เศษเปิดม้วน) ยังบันทึกในระบบไม่ได้ ให้จดแล้วแจ้งแอดมิน

บันทึกงานเสียคือการบอกว่า "วัสดุหายไปไหน" — บันทึกตรงตามจริงช่วยคุณ เพราะถ้าไม่บันทึก วัสดุที่หายจะดูเหมือนเศษเกินของงานอื่นแทน
