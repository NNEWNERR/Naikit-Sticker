ทุกคน

การเข้าสู่ระบบ

  1. เปิด https://naikit-sticker.web.app — ใช้ได้ทั้งคอมพิวเตอร์และมือถือ (มือถือมีแถบเมนูด้านล่าง)
  2. กรอกชื่อผู้ใช้ (username) และรหัสผ่านที่ได้รับจากแอดมิน
  3. เปลี่ยนรหัสผ่านเองได้ที่เมนูโปรไฟล์ (ต้องกรอกรหัสปัจจุบัน รหัสใหม่ยาวอย่างน้อย 8 ตัว)
  4. ถ้าลืมรหัสผ่าน → แจ้งแอดมินตั้งรหัสใหม่ให้ (หน้า login ไม่มีปุ่มลืมรหัสผ่าน)
  5. เข้าไม่ได้ทั้งที่รหัสถูก อาจเป็นเพราะบัญชีถูกปิดใช้งาน → ติดต่อแอดมิน

เมนูหลัก (เห็นเฉพาะเมนูที่ตำแหน่งของคุณใช้ได้)

เมนูใครเห็นใช้ทำอะไร
📋 หน้าหลักทุกคนคิวงานของตำแหน่งตัวเอง
➕ สร้างใบงานฝ่ายขาย, แอดมินเปิดใบงานใหม่
📊 งานทั้งหมดฝ่ายขาย, การเงิน, แอดมินดูรายงานงานทั้งหมด
✅ สรุปงานรายวันฝ่ายขาย, การเงิน, แอดมินสรุปงานประจำวัน
💰 ตรวจเงินการเงิน, แอดมินตรวจสอบเงิน กระทบยอด
👤 โปรไฟล์ทุกคนข้อมูลบัญชีตัวเอง + เปลี่ยนรหัสผ่าน
⚙️ ตั้งค่าแอดมินจัดการผู้ใช้ ราคากลาง และวัสดุ
จ่ายรวม (บันทึกจ่ายก้อนเดียวหลายใบงาน) ไม่อยู่ในเมนูข้าง — เป็นปุ่ม 💳 บนหน้าหลัก (ฝ่ายขาย/การเงิน/แอดมิน) และลิงก์ในหน้าตรวจเงิน

สถานะของใบงาน (เรียงตามลำดับงาน)

รอออกแบบ → กำลังออกแบบ → รอคอนเฟิร์มแบบ → คอนเฟิร์มแล้ว →
รอผลิต → กำลังผลิต → รอส่งมอบ → ส่งมอบแล้ว
สถานะความหมายใครทำขั้นต่อไป
รอออกแบบเพิ่งเปิดใบงาน รอกราฟิกรับงานกราฟิกกด รับงานนี้
กำลังออกแบบกราฟิกกำลังทำแบบกราฟิกแนบรูปแบบ แล้วกด ส่งแบบ
รอคอนเฟิร์มแบบรอฝ่ายขายตรวจแบบกับลูกค้าฝ่ายขายกด คอนเฟิร์ม หรือ ขอแก้
คอนเฟิร์มแล้วลูกค้าโอเคแบบแล้วกราฟิกกด 📦 ส่งเข้าผลิต
รอผลิตอยู่ในคิวผลิต รอคนพิมพ์รับงานฝ่ายผลิต (หรือกราฟิกถ้าเป็นงาน FUJI) กดรับงาน
กำลังผลิตกำลังพิมพ์คนพิมพ์แนบรูปงาน + บันทึกการพิมพ์
รอส่งมอบพิมพ์เสร็จทุกเครื่องแล้วฝ่ายขายส่งลูกค้า แล้วกด ส่งมอบ
ส่งมอบแล้วปิดงาน—
  • ใบงานที่มีป้าย ด่วน! สีแดง = งานเร่ง ให้ทำก่อน
  • งานที่มีหลายประเภท (เช่น ไวนิล + ตรายาง) จะแยกเป็นงานย่อยต่อเครื่อง — ต้องพิมพ์เสร็จทุกเครื่อง ใบงานถึงจะเป็น "รอส่งมอบ"

คอมเมนต์ในใบงาน

ทุกใบงานมีช่องคอมเมนต์ด้านล่าง ใช้คุยกันข้ามฝ่ายเกี่ยวกับงานนั้น (เช่น กราฟิกถามสเปค ฝ่ายขายแจ้งลูกค้าเปลี่ยนใจ) — ลบได้เฉพาะคอมเมนต์ของตัวเอง

ข้อควรระวังทั่วไป

กติกากลาง 3 ข้อ:
  • ทุกการกระทำถูกบันทึก — ระบบเก็บประวัติว่าใครทำอะไรเมื่อไหร่ (ดูได้ที่ "ประวัติการดำเนินการ" ท้ายใบงาน)
  • ตัวเลขเงินแก้เองไม่ได้หลังเปิดใบงาน — กรอกผิดต้องแจ้งฝ่ายการเงินหรือแอดมินปรับให้ พร้อมเหตุผล
  • อย่าแชร์รหัสผ่าน — งานที่ทำภายใต้บัญชีคุณถือว่าคุณเป็นคนทำ

ฝ่ายขาย (Seller)

SELLER

หน้าที่: เปิดใบงาน → คอนเฟิร์มแบบกับลูกค้า → รับเงิน → ส่งมอบงาน

เมนูที่ใช้ได้: หน้าหลัก · สร้างใบงาน · งานทั้งหมด · สรุปงานรายวัน · โปรไฟล์ (จ่ายรวม ไม่อยู่ในเมนูข้าง — เป็นปุ่ม 💳 บนหน้าหลัก)
เห็นเฉพาะใบงานที่ตัวเองเป็นคนเปิดเท่านั้น (ใบงานของฝ่ายขายคนอื่นมองไม่เห็น)

1เปิดใบงานใหม่

เมนู ➕ สร้างใบงาน แล้วกรอก:

  1. ข้อมูลลูกค้า — ชื่อ, ช่องทางติดต่อ (หน้าร้าน/เฟสบุ๊ค/ไลน์/อีเมล/โทรศัพท์), เบอร์โทร/ชื่อไลน์
  2. วันนัดรับงาน — วันที่ลูกค้าจะมารับ (ฝ่ายผลิตใช้จัดคิว)
  3. งานด่วน — ติ๊กเมื่อเป็นงานเร่ง จะขึ้นป้าย "ด่วน!" ให้ทุกฝ่ายเห็น
  4. รายการงาน (ใส่ได้หลายรายการ) — ประเภท, ขนาด, ตัวเลือก (ตาไก่/พับขอบ), จำนวน, ราคาต่อหน่วย
    ยอดรวมระบบคำนวณให้เอง = จำนวน × ราคาต่อหน่วย — พิมพ์ยอดรวมเองไม่ได้
  5. เงิน — ส่วนลด, มัดจำ, วิธีจ่าย, ค่าส่ง, ค่าธรรมเนียมโอน/เช็ค, ค่าใช้จ่ายอื่นๆ
    ใส่ "ค่าใช้จ่ายอื่นๆ" ต้องใส่หมายเหตุว่าค่าอะไร (ระบบบังคับ)
  6. รูป — รูปใบงาน + รูปอ้างอิงจากลูกค้า (สูงสุด 10 รูป)

บันทึกแล้วได้เลขใบงานอัตโนมัติ (เช่น NK-2604-018) และเข้าคิว "รอออกแบบ"

มอบหมายกราฟิกเองได้ — ไม่ต้องรอกราฟิกกดรับ: เปิดใบงาน (ขณะยังสถานะ "รอออกแบบ") กดปุ่ม 📨 ส่งให้กราฟิก แล้วเลือกคนที่ต้องการ เหมาะกับงานด่วนหรืองานที่คุยสเปคกับกราฟิกคนนั้นไว้แล้ว
⚠️ ขายต่ำกว่าราคากลางระวังติดธง — ระบบเทียบราคาที่ตั้งกับราคากลางอัตโนมัติ ถ้าต่ำกว่าเกณฑ์จะติดธงแดงไปที่ฝ่ายการเงิน ถ้าจำเป็นต้องลดราคา ใช้ช่องส่วนลดและเตรียมอธิบายเหตุผลได้

2แก้ไขใบงาน

แก้ได้เฉพาะช่วงที่งานยัง รอออกแบบ / กำลังออกแบบ / รอคอนเฟิร์มแบบ — หลังคอนเฟิร์มแบบแล้วต้องแจ้งแอดมิน

ตัวเลขเงิน (ส่วนลด/มัดจำ/วิธีจ่าย) แก้เองไม่ได้หลังเปิดใบงานไม่ว่าสถานะไหน — แจ้งฝ่ายการเงินหรือแอดมินปรับให้พร้อมเหตุผล

3คอนเฟิร์มแบบ

  1. งานสถานะ รอคอนเฟิร์มแบบ → เปิดใบงาน ดูรูปที่กราฟิกแนบ (หัวข้อ "ฝ่ายกราฟิก › รูปที่ออกแบบ")
  2. ส่งให้ลูกค้าดู
  3. ลูกค้าโอเค → กด คอนเฟิร์ม (งานไปต่อคิวผลิต)
  4. ลูกค้าขอแก้ → กด ขอแก้ แล้วเขียนคอมเมนต์บอกกราฟิกว่าแก้ตรงไหน
⚠️ คอนเฟิร์มแล้วย้อนกลับไม่ได้ — ตรวจกับลูกค้าให้ชัวร์ก่อนกด

4รับเงิน / บันทึกการจ่าย

ทุกครั้งที่ลูกค้าจ่าย (มัดจำตอนเปิดใบงานระบบบันทึกให้แล้ว):

  1. เปิดใบงาน → หัวข้อ การชำระเงิน (เงินสด/โอน/เช็ค)
  2. เลือกวิธีจ่าย ใส่จำนวนเงิน (ปุ่ม จ่ายเต็ม ใส่ยอดค้างให้อัตโนมัติ)
  3. โอน/เช็ค → แนบสลิป + ใส่เลขอ้างอิง (เงินสดไม่ต้องแนบ)
  4. กด บันทึก — ยอด "จ่ายจริงแล้ว" / "ค้างชำระจริง" อัปเดตอัตโนมัติ

จ่ายรวมหลายใบงาน — ลูกค้าโอนก้อนเดียวจ่ายหลายใบ กดปุ่ม 💳 จ่ายรวม บนหน้าหลัก เลือกใบงานแล้วกระจายยอดในครั้งเดียว

ขอคืนเงิน — กด ขอคืนเงิน ในใบงาน ใส่จำนวน วิธีคืน เหตุผล → รอฝ่ายการเงินอนุมัติ (คืนเงินเองเลยไม่ได้)

5ส่งมอบงาน

  1. งานสถานะ รอส่งมอบ = พิมพ์เสร็จแล้ว → ส่งงานให้ลูกค้า
  2. เปิดใบงาน กด ส่งมอบ — แนบสลิปงวดสุดท้ายได้ถ้ามี
  3. ส่งมอบทั้งที่ค้างชำระได้ (ลูกค้าเครดิต) — ยอดค้างขึ้นรายการลูกหนี้ให้การเงินตามต่อ

หลังส่งมอบ ระบบมีใบเสร็จ QR ให้ลูกค้าสแกนดูใบเสร็จออนไลน์ได้

6เงินสดประจำวัน

งานที่รับเงินสดและส่งมอบวันนั้น ระบบรวมยอดไว้ต่อคน — สิ้นวันนับเงินสดส่งฝ่ายการเงิน ฝ่ายการเงินจะกระทบยอดเทียบกับระบบ ถ้าไม่ตรง (ขาด/เกิน) จะติดธงและถูกสอบถาม นับให้ครบก่อนส่ง

7บันทึกงานเสีย

งานของคุณพิมพ์เสีย/ตัดเสีย (เช่น ลูกค้าเปลี่ยนแบบหลังพิมพ์) → ปุ่ม งานเสีย ในใบงานของตัวเอง ใส่เหตุผล วัสดุ ปริมาณที่เสีย เพื่อให้บัญชีวัสดุตรงความจริง

ฝ่ายกราฟิก (Graphic)

GRAPHIC

หน้าที่: รับงานออกแบบ → ส่งแบบให้ฝ่ายขายคอนเฟิร์ม → ส่งเข้าคิวผลิต และพิมพ์งานเครื่อง FUJI (ตรายาง) ด้วย

เมนูที่ใช้ได้: หน้าหลัก · โปรไฟล์ — หน้าหลักแสดง 2 กลุ่ม: คิวกลาง (งาน "รอออกแบบ" ที่ยังไม่มีใครรับ) และ งานของฉัน (งานที่รับแล้ว)

1รับงานออกแบบ

  1. ดูคิวกลางในหน้าหลัก — งานป้าย ด่วน! รับก่อน และดูวันนัดรับงานประกอบ
  2. เปิดใบงาน อ่านรายละเอียด (ประเภท ขนาด ตัวเลือก จำนวน) + รูปใบงาน + รูปอ้างอิงจากลูกค้า
  3. กด รับงานนี้ — งานเปลี่ยนเป็น "กำลังออกแบบ" และย้ายมาอยู่ในงานของฉัน
รับแล้วงานเป็นของคุณ คนอื่นรับซ้ำไม่ได้ — ถ้ารับผิด งานล้นมือ หรือลาหยุด กดปุ่ม 🔄 ส่งต่องาน ในใบงานเพื่อโอนให้กราฟิกคนอื่นได้เอง (ทำได้ขณะสถานะ "กำลังออกแบบ")
บางงานฝ่ายขายจะกด 📨 ส่งให้กราฟิก มอบหมายมาถึงคุณโดยตรงโดยไม่ผ่านคิวกลาง — งานแบบนี้โผล่ใน "งานของฉัน" ทันที

2ออกแบบและส่งแบบ

  1. ทำแบบตามสเปคในใบงาน — สงสัยอะไรถามฝ่ายขายผ่านคอมเมนต์ในใบงาน
  2. เปิดใบงาน → แนบรูปแบบงาน (บังคับ) — อัปโหลดรูปแบบที่เสร็จแล้ว
  3. กด ส่งแบบ — งานเปลี่ยนเป็น "รอคอนเฟิร์มแบบ" รอฝ่ายขายตรวจกับลูกค้า

3ถ้าโดนขอแก้

ฝ่ายขายกด "ขอแก้" งานกลับมาเป็น กำลังออกแบบ ในมือคุณ — อ่านคอมเมนต์ว่าแก้ตรงไหน → แก้ → แนบรูปใหม่ → ส่งแบบ อีกครั้ง (วนได้จนกว่าจะผ่าน)

4ส่งเข้าคิวผลิต

เมื่อฝ่ายขายคอนเฟิร์มแบบแล้ว (สถานะ คอนเฟิร์มแล้ว) หน้าที่สุดท้ายของคุณ: กด 📦 ส่งเข้าผลิต — ระบบแตกงานเป็นงานย่อยตามเครื่องพิมพ์ที่ต้องใช้ แล้วเข้าคิวฝ่ายผลิต

⚠️ อย่าลืมขั้นนี้ — งานที่ค้างสถานะ "คอนเฟิร์มแล้ว" คือแบบผ่านแล้วแต่ยังไม่เข้าคิวผลิต ลูกค้ารอฟรี

5พิมพ์งานเครื่อง FUJI (งานตรายาง)

งานที่ใช้เครื่อง FUJI เป็นหน้าที่ทีมกราฟิก (ไม่ใช่ฝ่ายผลิต):

  1. งาน FUJI ในคิวผลิตจะโผล่ให้ทีมกราฟิกเห็น — กด รับงานนี้ ที่งานย่อยเครื่อง FUJI
  2. พิมพ์งานจริง
  3. เปิดใบงาน → แนบรูปงานพิมพ์ (บังคับ) + กรอก บันทึกการพิมพ์: วัสดุที่ใช้ · หน้ากว้างม้วน · ความยาวที่ใช้จริง (เมตร) · จำนวนที่พิมพ์จริง
  4. บันทึกแล้วงานย่อย FUJI เสร็จ — ทุกเครื่องเสร็จครบ ใบงานเป็น "รอส่งมอบ"

คนแนบรูป/บันทึกไม่ต้องเป็นคนเดียวกับคนกดรับ — ขอแค่อยู่ทีมที่ดูแลเครื่องนั้น

⚠️ กรอกความยาวที่ใช้จริงตามจริง — ระบบคำนวณเปอร์เซ็นต์เศษวัสดุอัตโนมัติ เศษสูงผิดปกติจะติดธงไปฝ่ายการเงิน กรอกผิดแก้ได้ที่ปุ่ม ✏️ แก้บันทึก (ต้องใส่เหตุผล — ระบบเก็บค่าก่อน/หลังแก้ลงประวัติเสมอ)

6บันทึกงานเสีย

พิมพ์เสีย / เครื่องมีปัญหา / สีเพี้ยน → กด งานเสีย ในใบงาน บันทึกเหตุผล วัสดุ ปริมาณที่เสีย — บันทึกตรงตามจริง ข้อมูลนี้ใช้ตามวัสดุที่หายไป ไม่ได้ใช้ลงโทษคนพิมพ์

คำถามที่พบบ่อย — ฝ่ายกราฟิก

ปัญหาทางแก้
รับงานผิด / ทำต่อไม่ได้กดปุ่ม 🔄 ส่งต่องาน โอนให้กราฟิกคนอื่นเอง (ขณะสถานะกำลังออกแบบ)
แบบผ่านแล้วแต่ลูกค้าเปลี่ยนใจฝ่ายขายต้องแจ้งแอดมินย้อนสถานะ — คุณแก้เองไม่ได้
กรอกบันทึกการพิมพ์ผิดกด ✏️ แก้บันทึก ในหัวข้อ "บันทึกการพิมพ์ที่บันทึกแล้ว" — ใส่เหตุผล ระบบลงประวัติให้
ไม่เห็นเมนูสร้างใบงาน/รายงานปกติ — เมนูเหล่านั้นเป็นของฝ่ายขาย/การเงิน

ฝ่ายผลิต (Production)

PRODUCTION

หน้าที่: รับงานพิมพ์ → พิมพ์ → แนบรูปงาน + บันทึกการพิมพ์และวัสดุ

เมนูที่ใช้ได้: หน้าหลัก · โปรไฟล์ — หน้าหลักแสดง 2 กลุ่ม: คิวกลาง (งาน "คอนเฟิร์มแล้ว / รอผลิต" ที่ยังไม่มีใครรับ) และ งานของฉัน

เครื่องที่ทีมผลิตดูแล

ใบงานหนึ่งใบอาจมีงานหลายเครื่อง ระบบแตกเป็นงานย่อยต่อเครื่องให้อัตโนมัติ:

เครื่องทีมที่ทำ
ไวนิล / สติกเกอร์ใหญ่ / สติกเกอร์ตัด / อื่นๆฝ่ายผลิต
FUJI (ตรายาง)ทีมกราฟิก

แต่ละเครื่องรับงาน/ทำเสร็จแยกกันอิสระ — แต่ใบงานจะเป็น "รอส่งมอบ" ก็ต่อเมื่อทุกเครื่องเสร็จครบ

1รับงานพิมพ์

  1. ดูคิวกลาง — งานป้าย ด่วน! ทำก่อน และดูวันนัดรับงานประกอบการจัดคิว
  2. เปิดใบงาน ดูรายละเอียด: ประเภท ขนาด ตัวเลือก (ตาไก่/พับขอบ) จำนวน + รูปแบบที่คอนเฟิร์มแล้ว (หัวข้อ "ฝ่ายกราฟิก › รูปที่ออกแบบ" — พิมพ์ตามแบบนี้เท่านั้น)
  3. ที่หัวข้อ งานพิมพ์แต่ละเครื่อง กด รับงานนี้ ตรงเครื่องที่คุณจะทำ

2พิมพ์และบันทึกการพิมพ์

พิมพ์เสร็จแล้ว เปิดใบงานทำ 2 อย่าง (บังคับทั้งคู่):

2.1 แนบรูปงานพิมพ์ (บังคับ)

ถ่ายรูปงานที่พิมพ์จริง อัปโหลดเข้าใบงาน

2.2 กรอกบันทึกการพิมพ์ ต่อรายการงาน

ช่องกรอกอะไร
วัสดุเลือกจากรายการ (เช่น ดีรุยเซ่น หลังขาว, HP)
หลังขาว/ดำ/เทาเฉพาะงานไวนิล
หน้ากว้างม้วนเลือกตามม้วนที่ใช้จริง (เช่น 1.32 / 1.62 / 3.22 ม.)
ความยาวที่ใช้ (เมตร)วัดจากม้วนจริง รวมส่วนที่เผื่อ/เล็ม — ไม่ใช่ขนาดชิ้นงาน
จำนวนพิมพ์จริงระบบใส่ให้เท่าจำนวนสั่ง แก้ได้ถ้าพิมพ์เผื่อ
พิมพ์รวมม้วนจัดวางหลายรายการบนม้วนเดียวกัน ให้ผูกเป็นชุดเดียวกัน — ระบบจะเฉลี่ยวัสดุให้ถูก

บันทึกครบแล้วงานย่อยเครื่องนั้น = เสร็จ

⚠️ กรอกตามจริงเสมอ — ระบบคำนวณพื้นที่ที่ใช้เทียบกับพื้นที่ที่ขาย ออกมาเป็นเปอร์เซ็นต์เศษวัสดุอัตโนมัติ ถ้าเกินเกณฑ์ (ประมาณ 30% เตือน / 50% ธงแดง) จะขึ้นรายงานที่ฝ่ายการเงิน — เศษเยอะเพราะงานชิ้นเล็กจัดวางไม่ลงตัวเป็นเรื่องปกติ อธิบายได้ แต่ตัวเลขที่กรอกมั่วจะตรวจเจอตอนกระทบยอดม้วนวัสดุ

3กรอกผิด แก้ยังไง

แก้ได้เองในใบงาน:

  1. เปิดใบงาน → หัวข้อ บันทึกการพิมพ์ที่บันทึกแล้ว
  2. กด ✏️ แก้บันทึก ที่รายการที่ผิด → แก้วัสดุ/ม้วน/ความยาว/จำนวนให้ถูก
  3. ใส่เหตุผลที่แก้ (บังคับ เช่น "กรอกความยาวผิด วัดใหม่ได้ 4.2 ม.") → กด 💾 บันทึกการแก้
  • แก้ได้เฉพาะรายการของทีมเครื่องตัวเอง (งาน FUJI ทีมกราฟิกแก้ / เครื่องอื่นทีมผลิตแก้)
  • ระบบเก็บค่าก่อน/หลังแก้ + เหตุผล ลงประวัติใบงานเสมอ — ชื่อผู้พิมพ์เดิมไม่เปลี่ยน
  • เศษวัสดุคำนวณใหม่อัตโนมัติจากค่าที่แก้

4บันทึกงานเสีย

พิมพ์เสีย ตัดเสีย เครื่องมีปัญหา สีเพี้ยน วัสดุมีตำหนิ → กด งานเสีย ในใบงาน:

  1. เลือกเหตุผล (เลือก "อื่นๆ" ต้องพิมพ์รายละเอียด)
  2. เลือกวัสดุ หน้ากว้างม้วน ความยาวที่เสีย จำนวนที่เสีย
  3. บันทึก — แล้วพิมพ์ใหม่ + บันทึกการพิมพ์รอบใหม่ตามปกติ

การบันทึกงานเสียทำจากในใบงานเท่านั้น — วัสดุที่เสียโดยไม่เกี่ยวกับใบงานไหนเลย (เช่น ทดสอบเครื่อง เศษเปิดม้วน) ยังบันทึกในระบบไม่ได้ ให้จดแล้วแจ้งแอดมิน

บันทึกงานเสียคือการบอกว่า "วัสดุหายไปไหน" — บันทึกตรงตามจริงช่วยคุณ เพราะถ้าไม่บันทึก วัสดุที่หายจะดูเหมือนเศษเกินของงานอื่นแทน

ปัญหาทางแก้

บันทึกงานเสียผิดแจ้งแอดมินยกเลิกรายการให้ แล้วบันทึกใหม่

ฝ่ายการเงิน (Finance)

FINANCE

หน้าที่: ตรวจสอบเงินทุกทาง — กระทบยอด อนุมัติคืนเงิน ตามลูกหนี้ ตรวจธงแดง

อ่านข้อมูลได้ทั้งหมด (ทุกใบงาน ทุกฝ่ายขาย) แต่ไม่ได้ทำงาน workflow (ไม่สร้างใบงาน ไม่คอนเฟิร์มแบบ ไม่พิมพ์) — สิ่งเดียวที่แก้ได้คือตัวเลขเงิน พร้อมเหตุผลกำกับ

เมนูที่ใช้ได้: หน้าหลัก · งานทั้งหมด · สรุปงานรายวัน · ตรวจเงิน · โปรไฟล์ (จ่ายรวม ไม่อยู่ในเมนูข้าง — เข้าจากปุ่ม 💳 บนหน้าหลัก หรือลิงก์ "บันทึกจ่ายรวม" ในหน้าตรวจเงิน)

หน้า "ตรวจเงิน" — งานหลัก

ยอดรวมด้านบน: ยอดขาย (เฉพาะงานส่งมอบแล้ว) · ยอดเงินสด · สัดส่วนเงินสด · จำนวนครั้งที่เปลี่ยนยอดเงิน

1งานติดธงแดง (ขายต่ำกว่าราคากลาง)

ระบบเทียบราคาขายจริงกับราคากลางอัตโนมัติทุกใบงาน — ตารางแสดงใบงาน ผู้ขาย ราคากลาง ขายจริง ส่วนต่าง ระดับ
สิ่งที่ต้องทำ: ไล่ดูรายคน — ธงกระจุกที่ผู้ขายคนใดบ่อยผิดปกติ ให้สอบถามเหตุผลรายใบ

2กระทบยอดเงินสดรายวัน

  1. เลือกผู้ขาย + วันที่ — ระบบแสดงยอดตามระบบ (งานเงินสดที่ส่งมอบวันนั้น)
  2. กรอกยอดที่นับได้จริง → ระบบคำนวณส่วนต่าง
  3. ส่วนต่าง ≠ 0 = ธงแดง — สอบถามผู้ขายก่อนปิด ใส่คำอธิบายในหมายเหตุ
  4. เรียบร้อยแล้วกด ปิดรอบ — ปิดแล้วแก้ไม่ได้

3กระทบยอดโอน/เช็ค (เทียบ statement)

ตารางรวมรายการโอน/เช็คในระบบ (วันที่ วิธี เลขอ้างอิง ยอด งานที่ผูก) — ไล่เทียบกับ statement ธนาคารจริง
เลขอ้างอิงซ้ำระบบติดธงให้ (สลิปใบเดียวใช้ซ้ำ)

4คำขอคืนเงิน — อนุมัติ/ปฏิเสธ

ฝ่ายขายขอคืนเงินได้แต่คืนเองไม่ได้ ทุกคำขอมารอที่นี่: ตรวจเหตุผล + ยอด (เกินยอดที่ลูกค้าจ่ายจริงไม่ได้) → อนุมัติ หรือ ปฏิเสธ

5ลูกหนี้ค้างชำระ

งานส่งมอบแล้วแต่จ่ายไม่ครบ (ขายเครดิต) — ใช้ตามทวงถาม งานปิดเมื่อยอดจ่ายจริง ≥ ยอดรับสุทธิ (งานที่โดนหัก ณ ที่จ่ายจะปิดได้ ไม่ค้างตลอดกาล)

6ประวัติการเปลี่ยนยอดเงิน (audit)

ทุกการปรับยอดโดยใครก็ตาม แสดง ก่อน→หลัง + คนทำ + เหตุผล — ไล่ดูความผิดปกติได้ที่นี่

7รายงานเศษวัสดุ + กระทบยอดวัสดุ

  • รายงานเศษ (waste report) — งานที่เศษวัสดุเกินเกณฑ์ (เตือน ~30% / ธงแดง ~50%) และงานเสียทั้งหมด
  • กระทบยอดวัสดุ (material reconcile) — เทียบวัสดุที่ระบบบันทึกว่าใช้ กับม้วนจริงในสต็อก
  • เศษสูงกระจุกที่คนพิมพ์คนเดียว/วัสดุตัวเดียว = จุดที่ควรเข้าไปดู

การปรับยอดเงิน (adjust payment)

ฝ่ายขายกรอกส่วนลด/มัดจำ/วิธีจ่ายผิด → ปรับให้ได้ในใบงาน (ปุ่ม ปรับยอดเงิน):

แก้ได้ส่วนลด · มัดจำ · วิธีจ่าย · วันจ่าย · ค่าส่ง · ค่าธรรมเนียม · ค่าใช้จ่ายอื่นๆ · VAT/หัก ณ ที่จ่าย
แก้ไม่ได้ยอดรวม — ระบบคำนวณจากรายการงานเสมอ (ต้องแก้รายการงาน = งานของแอดมิน)
บังคับต้องใส่เหตุผลทุกครั้ง และลง audit อัตโนมัติ

หลักที่ควรยึด

  • ตัวเลขที่ระบบคำนวณ (ยอดรวม เศษวัสดุ ส่วนต่างเงินสด) เชื่อได้ — คำนวณฝั่งเซิร์ฟเวอร์ พนักงานพิมพ์ทับไม่ได้
  • ธงแดงคือ "จุดที่ควรถาม" ไม่ใช่ "หลักฐานความผิด" — ถามก่อนสรุปเสมอ
  • ทุกอย่างที่คุณทำ (อนุมัติ ปรับยอด ปิดรอบ) ก็ลง audit เช่นกัน

ผู้ดูแลระบบ (Admin)

ADMIN

1จัดการผู้ใช้ (ตั้งค่า › ผู้ใช้)

งานวิธีทำหมายเหตุ

เปลี่ยนตำแหน่ง เลือกตำแหน่งใหม่ พนักงานถูกบังคับ login ใหม่ทันที · เปลี่ยนตำแหน่งตัวเองออกจาก admin ไม่ได้
ปิดบัญชี (ลาออก) ปิดสวิตช์ "ใช้งาน" ถูกดีดออกทันทีทุกเครื่อง · ปิดบัญชีตัวเองไม่ได้ · อย่าลบ ให้ปิดแทน — ประวัติงานยังอยู่
ตั้งรหัสผ่านใหม่ (ลืมรหัส) Reset password หลุดจากระบบทุกเครื่อง ต้อง login ใหม่ · ใช้เฉพาะกรณีลืมรหัส — ถ้าแค่อยากเปลี่ยน พนักงานเปลี่ยนเองได้ที่หน้าโปรไฟล์ (ต้องรู้รหัสปัจจุบัน)

ตำแหน่งที่มี: seller (ฝ่ายขาย) · graphic (กราฟิก — รวมพิมพ์ FUJI) · production (ฝ่ายผลิต) · finance (การเงิน — อ่านได้หมด แก้ได้เฉพาะเงิน) · admin

⚠️ ให้ตำแหน่งตามหน้าที่จริงเท่านั้น — โดยเฉพาะ admin กับ finance ให้เท่าที่จำเป็น

2จัดการราคากลาง (ตั้งค่า › ราคากลาง)

ราคากลางต่อประเภทงาน + ตัวเลือก (เช่น ไวนิล+ตาไก่) — ระบบใช้เทียบกับราคาขายจริง ของฝ่ายขายอัตโนมัติ ถ้าขายต่ำกว่าเกณฑ์จะติดธงแดงที่หน้าตรวจเงิน

  • เพิ่ม/แก้ด้วยปุ่ม + เพิ่มราคากลาง ในหน้าตั้งค่า
  • อัปเดตทุกครั้งที่ต้นทุนหรือนโยบายราคาเปลี่ยน — ราคากลางที่ล้าสมัยทำให้ธงแดงมั่ว (งานปกติโดนธง / งานกดราคาหลุดรอด) แล้วฝ่ายการเงินจะตรวจเพี้ยนทั้งระบบ
  • ถ้ายังไม่เคยตั้งเลย มี seed script ให้ (scripts/seed-rate-cards.ts — งานฝั่งเทคนิค)

3จัดการวัสดุ (ตั้งค่า › วัสดุ)

รายการวัสดุที่คนพิมพ์เลือกตอนบันทึกการพิมพ์:

  • เพิ่ม/แก้: หมวด (ไวนิล/สติกเกอร์), ยี่ห้อ, ป้ายชื่อ, หน้ากว้างม้วนที่มีจริง, ต้นทุนต่อตารางเมตร (ถ้ารู้)
  • วัสดุเลิกใช้ → ปิด active (หายจาก dropdown แต่ประวัติเก่ายังอยู่) — อย่าลบ
  • หน้ากว้างม้วนต้องตรงกับม้วนที่ซื้อจริง ไม่งั้นคนพิมพ์เลือกไม่ได้/เลือกผิด แล้วตัวเลขเศษจะเพี้ยนทั้งระบบ

4แก้งานแทนพนักงาน (กรณีที่พบบ่อย)

พนักงานแจ้งว่าสิ่งที่ต้องทำ
กราฟิก/คนพิมพ์รับงานผิดคน หรือลาป่วยงานค้างเปิดใบงาน → ย้ายงาน (reassign) ให้คนใหม่ · งานออกแบบที่ยัง "กำลังออกแบบ" กราฟิกใช้ปุ่ม 🔄 ส่งต่องาน กันเองได้ ไม่ต้องผ่านคุณ
คนพิมพ์กรอกบันทึกการพิมพ์ผิด (วัสดุ/ความยาว)ระบบยังไม่มีเครื่องมือแก้บันทึกการพิมพ์ — จดเลขใบงาน + ค่าที่ถูกต้องไว้ แล้วแจ้งผู้พัฒนาแก้ข้อมูลหลังบ้าน (แก้ก่อนฝ่ายการเงินปิดรอบตรวจเศษวัสดุ)
ฝ่ายขายคอนเฟิร์มผิด / ลูกค้าเปลี่ยนใจหลังคอนเฟิร์มเปิดใบงาน → ปุ่ม 🔀 ปรับสถานะ (admin) เลือกสถานะใหม่ + ใส่เหตุผล (บังคับ ลงประวัติเสมอ) — ข้ามขั้นได้ทุกสถานะ ใช้เท่าที่จำเป็น
ต้องแก้ใบงานหลังคอนเฟิร์ม (ขนาด/รายการ)แอดมินแก้ได้ทุกสถานะ — แก้รายการงานแล้วยอดเงินคำนวณใหม่อัตโนมัติ
เปิดใบงานผิด ต้องลบลบใบงาน (soft delete — กู้คืนได้ทีหลัง)
บันทึกงานเสียผิดรายการยกเลิก (void) รายการงานเสียนั้น แล้วให้บันทึกใหม่
กรอกยอดเงินผิดปรับยอดเงินในใบงาน (ใส่เหตุผล — ลง audit เสมอ)
วัสดุไม่มีใน dropdownเพิ่มที่ ตั้งค่า › วัสดุ

5สิ่งที่ควรรู้เกี่ยวกับระบบ

  • ทุก action ลง audit — รวมของแอดมินเอง ดูได้ท้ายใบงาน + หน้าตรวจเงิน
  • ยอดรวมเงินเป็นของระบบ — คำนวณจากรายการงานฝั่งเซิร์ฟเวอร์เสมอ ไม่มีใครพิมพ์ทับได้ (รวมแอดมิน) ต้องการเปลี่ยนยอด = แก้รายการงานหรือส่วนลด
  • ลบ = ซ่อน — ใบงานที่ลบกู้คืนได้ ไม่มีอะไรหายถาวรจากหน้าจอ
  • ใบเสร็จลูกค้าเปิดผ่านลิงก์ QR ได้โดยไม่ต้อง login — เป็นหน้าสาธารณะที่ตั้งใจให้เป็นแบบนั้น
  • เรื่องเชิงเทคนิค (deploy, schema, Cloud Functions) ดู SCHEMA.md และ docs/ ในโปรเจกต์ — คู่มือชุดนี้สำหรับผู้ใช้งานเท่านั้น
