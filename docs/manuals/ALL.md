# พื้นฐานสำหรับทุกตำแหน่ง

## การเข้าสู่ระบบ

1. เปิด https://naikit-sticker.web.app
2. กรอก **ชื่อผู้ใช้ (username)** และ **รหัสผ่าน** ที่ได้รับจากแอดมิน
3. เปลี่ยนรหัสผ่านเองได้ที่เมนู **โปรไฟล์** (ต้องกรอกรหัสปัจจุบัน รหัสใหม่ยาวอย่างน้อย 8 ตัว)
4. ถ้า**ลืม**รหัสผ่าน → แจ้งแอดมินให้ตั้งรหัสใหม่ให้ (หน้า login ไม่มีปุ่มลืมรหัสผ่าน)
5. ถ้าเข้าระบบไม่ได้ทั้งที่รหัสถูก อาจเป็นเพราะบัญชีถูกปิดใช้งาน → ติดต่อแอดมิน

## เมนูหลัก (เห็นเฉพาะเมนูที่ตำแหน่งของคุณใช้ได้)

| เมนู | ใครเห็น | ใช้ทำอะไร |
|---|---|---|
| 📋 หน้าหลัก | ทุกคน | คิวงานของตำแหน่งตัวเอง |
| ➕ สร้างใบงาน | ฝ่ายขาย, แอดมิน | เปิดใบงานใหม่ |
| 📊 งานทั้งหมด | ฝ่ายขาย, การเงิน, แอดมิน | ดูรายงานงานทั้งหมด |
| ✅ สรุปงานรายวัน | ฝ่ายขาย, การเงิน, แอดมิน | สรุปงานประจำวัน |
| 💰 ตรวจเงิน | การเงิน, แอดมิน | ตรวจสอบเงิน กระทบยอด |
| 👤 โปรไฟล์ | ทุกคน | ข้อมูลบัญชีตัวเอง + เปลี่ยนรหัสผ่าน |
| ⚙️ ตั้งค่า | แอดมิน | จัดการผู้ใช้ ราคากลาง และวัสดุ |

> **จ่ายรวม** (บันทึกจ่ายก้อนเดียวหลายใบงาน) ไม่อยู่ในเมนูข้าง —
> เป็นปุ่ม 💳 บนหน้าหลัก (ฝ่ายขาย/การเงิน/แอดมิน) และลิงก์ในหน้าตรวจเงิน

## สถานะของใบงาน (เรียงตามลำดับงาน)

```
รอออกแบบ → กำลังออกแบบ → รอคอนเฟิร์มแบบ → คอนเฟิร์มแล้ว
        → รอผลิต → กำลังผลิต → รอส่งมอบ → ส่งมอบแล้ว
```

| สถานะ | ความหมาย | ใครทำขั้นต่อไป |
|---|---|---|
| รอออกแบบ | เพิ่งเปิดใบงาน รอกราฟิกรับงาน | กราฟิกกด **รับงานนี้** |
| กำลังออกแบบ | กราฟิกกำลังทำแบบ | กราฟิกแนบรูปแบบ แล้วกด **ส่งแบบ** |
| รอคอนเฟิร์มแบบ | รอฝ่ายขายตรวจแบบกับลูกค้า | ฝ่ายขายกด **คอนเฟิร์ม** หรือ **ขอแก้** |
| คอนเฟิร์มแล้ว | ลูกค้าโอเคแบบแล้ว | กราฟิกกด **ส่งเข้าผลิต** |
| รอผลิต | อยู่ในคิวผลิต รอคนพิมพ์รับงาน | ฝ่ายผลิต (หรือกราฟิกถ้าเป็นงาน FUJI) กดรับงาน |
| กำลังผลิต | กำลังพิมพ์ | คนพิมพ์แนบรูปงาน + บันทึกการพิมพ์ |
| รอส่งมอบ | พิมพ์เสร็จทุกเครื่องแล้ว | ฝ่ายขายส่งลูกค้า แล้วกด **ส่งมอบ** |
| ส่งมอบแล้ว | ปิดงาน | — |

- ใบงานที่มีป้าย **ด่วน!** สีแดง = งานเร่ง ให้ทำก่อน
- งานที่มีหลายประเภท (เช่น ไวนิล + ตรายาง) จะแยกเป็นงานย่อยต่อเครื่อง —
  ต้องพิมพ์เสร็จ **ทุกเครื่อง** ใบงานถึงจะเป็น "รอส่งมอบ"

## คอมเมนต์ในใบงาน

ทุกใบงานมีช่องคอมเมนต์ด้านล่าง ใช้คุยกันข้ามฝ่ายเกี่ยวกับงานนั้น
(เช่น กราฟิกถามสเปค ฝ่ายขายแจ้งลูกค้าเปลี่ยนใจ) — ลบได้เฉพาะคอมเมนต์ของตัวเอง

## ข้อควรระวังทั่วไป (กติกากลาง 3 ข้อ)

- **ทุกการกระทำถูกบันทึก** — ระบบเก็บประวัติว่าใครทำอะไรเมื่อไหร่ในทุกใบงาน
  (ดูได้ที่ "ประวัติการดำเนินการ" ท้ายใบงาน)
- **ตัวเลขเงินแก้เองไม่ได้หลังเปิดใบงาน** — ถ้ากรอกยอด/มัดจำ/ส่วนลดผิด
  ต้องแจ้งฝ่ายการเงินหรือแอดมินปรับให้ พร้อมบอกเหตุผล
- **อย่าแชร์รหัสผ่านกับคนอื่น** — งานที่ทำภายใต้บัญชีคุณถือว่าคุณเป็นคนทำ

# ฝ่ายขาย (Seller)

**หน้าที่:** เปิดใบงาน → คอนเฟิร์มแบบกับลูกค้า → รับเงิน → ส่งมอบงาน

**เมนูที่ใช้ได้:** หน้าหลัก · สร้างใบงาน · งานทั้งหมด · สรุปงานรายวัน · โปรไฟล์
(**จ่ายรวม** ไม่อยู่ในเมนูข้าง — เป็นปุ่ม 💳 บนหน้าหลัก)
เห็นเฉพาะ**ใบงานที่ตัวเองเป็นคนเปิด**เท่านั้น (ใบงานของฝ่ายขายคนอื่นมองไม่เห็น)

## 1. เปิดใบงานใหม่

เมนู **➕ สร้างใบงาน** แล้วกรอก:

1. **ข้อมูลลูกค้า** — ชื่อลูกค้า, ช่องทางติดต่อ (หน้าร้าน/เฟสบุ๊ค/ไลน์/อีเมล/โทรศัพท์), เบอร์โทร/ชื่อไลน์
2. **วันนัดรับงาน** — วันที่ลูกค้าจะมารับ (สำคัญ ฝ่ายผลิตใช้จัดคิว)
3. **งานด่วน** — ติ๊กเมื่อเป็นงานเร่ง จะขึ้นป้าย "ด่วน!" ให้ทุกฝ่ายเห็น
4. **รายการงาน** (ใส่ได้หลายรายการ) — ประเภท (ไวนิล/สติกเกอร์/ตรายาง ฯลฯ), ขนาด, ตัวเลือก (ตาไก่/พับขอบ), จำนวน, ราคาต่อหน่วย
   - **ยอดรวมระบบคำนวณให้เอง** = จำนวน × ราคาต่อหน่วย ทุกรายการ — พิมพ์ยอดรวมเองไม่ได้
5. **เงิน** — ส่วนลด, มัดจำ, วิธีจ่าย (เงินสด/โอน/เช็ค/เครดิต), ค่าส่ง, ค่าธรรมเนียมโอน/เช็ค, ค่าใช้จ่ายอื่นๆ
   - ถ้าใส่ "ค่าใช้จ่ายอื่นๆ" **ต้องใส่หมายเหตุว่าค่าอะไร** ระบบบังคับ
6. **รูป** — รูปใบงาน (worksheet) และรูปอ้างอิงจากลูกค้า (สูงสุด 10 รูป)

บันทึกแล้วใบงานจะได้เลขที่อัตโนมัติ (เช่น NK-2604-018) และเข้าคิว "รอออกแบบ" ให้กราฟิกรับงานต่อ

**มอบหมายกราฟิกเองได้** — ไม่ต้องรอกราฟิกกดรับ: เปิดใบงาน (ขณะยังสถานะ "รอออกแบบ")
กดปุ่ม **📨 ส่งให้กราฟิก** แล้วเลือกคนที่ต้องการ เหมาะกับงานด่วนหรืองานที่คุยสเปคกับกราฟิกคนนั้นไว้แล้ว

> ⚠️ **ขายต่ำกว่าราคากลางระวังติดธง** — ระบบเทียบราคาที่คุณตั้งกับราคากลางอัตโนมัติ
> ถ้าต่ำกว่าเกณฑ์จะติดธงแดงไปโผล่ที่หน้าตรวจเงินของฝ่ายการเงิน
> ถ้าจำเป็นต้องลดราคาให้ลูกค้า ใช้ช่อง **ส่วนลด** และเตรียมอธิบายเหตุผลได้

## 2. แก้ไขใบงาน

แก้ได้เฉพาะช่วงที่งานยัง **รอออกแบบ / กำลังออกแบบ / รอคอนเฟิร์มแบบ**
หลังคอนเฟิร์มแบบแล้วแก้เองไม่ได้ — ต้องแจ้งแอดมิน

**ตัวเลขเงิน (ส่วนลด/มัดจำ/วิธีจ่าย) แก้เองไม่ได้หลังเปิดใบงาน** ไม่ว่าสถานะไหน —
แจ้งฝ่ายการเงินหรือแอดมินปรับให้ พร้อมเหตุผล (ระบบบันทึกทุกการปรับ)

## 3. คอนเฟิร์มแบบ

เมื่อกราฟิกส่งแบบ งานจะเป็นสถานะ **รอคอนเฟิร์มแบบ** — หน้าที่คุณ:

1. เปิดใบงาน ดูรูปแบบที่กราฟิกแนบไว้ (หัวข้อ "ฝ่ายกราฟิก > รูปที่ออกแบบ")
2. ส่งให้ลูกค้าดู
3. ลูกค้าโอเค → กด **คอนเฟิร์ม** (งานไปต่อคิวผลิต)
4. ลูกค้าขอแก้ → กด **ขอแก้** แล้วเขียนคอมเมนต์บอกกราฟิกว่าแก้ตรงไหน

> คอนเฟิร์มแล้ว **ย้อนกลับไม่ได้** — ตรวจกับลูกค้าให้ชัวร์ก่อนกด

## 4. รับเงิน / บันทึกการจ่าย

ทุกครั้งที่ลูกค้าจ่ายเงิน (มัดจำตอนเปิดใบงานระบบบันทึกให้แล้ว) ให้บันทึกในใบงาน:

1. เปิดใบงาน → หัวข้อ **การชำระเงิน (เงินสด/โอน/เช็ค)**
2. เลือกวิธีจ่าย ใส่จำนวนเงิน (ปุ่ม **จ่ายเต็ม** ใส่ยอดค้างให้อัตโนมัติ)
3. โอน/เช็ค → **แนบสลิป** และใส่เลขอ้างอิง (เงินสดไม่ต้องแนบ)
4. กด **บันทึก**

ยอด "จ่ายจริงแล้ว" และ "ค้างชำระจริง" ในใบงานจะอัปเดตอัตโนมัติ

**จ่ายรวมหลายใบงาน** — ลูกค้าโอนก้อนเดียวจ่ายหลายใบ กดปุ่ม **💳 จ่ายรวม** บนหน้าหลัก
เลือกใบงานแล้วกระจายยอดลงแต่ละใบได้ในครั้งเดียว

**ขอคืนเงิน** — ถ้าต้องคืนเงินลูกค้า กด **ขอคืนเงิน** ในใบงาน ใส่จำนวน วิธีคืน และเหตุผล
คำขอจะไปรอฝ่ายการเงินอนุมัติ (คืนเงินเองเลยไม่ได้)

## 5. ส่งมอบงาน

งานสถานะ **รอส่งมอบ** = พิมพ์เสร็จแล้ว:

1. ส่งงานให้ลูกค้า / ลูกค้ามารับ
2. เปิดใบงาน กด **ส่งมอบ** — แนบสลิปการจ่ายงวดสุดท้ายได้ถ้ามี
3. ส่งมอบทั้งที่ยังค้างชำระได้ (ลูกค้าเครดิต) — ยอดค้างจะไปขึ้นรายการลูกหนี้ที่ฝ่ายการเงินตามต่อ

หลังส่งมอบ ระบบมี **ใบเสร็จ QR** ให้ลูกค้าสแกนดูใบเสร็จออนไลน์ได้

## 6. เงินสดประจำวัน

งานที่รับ **เงินสด** และส่งมอบในวันนั้น ระบบรวมยอดไว้ให้ต่อคน
สิ้นวันให้นับเงินสดส่งฝ่ายการเงิน — ฝ่ายการเงินจะกระทบยอดเทียบกับระบบ
ถ้ายอดไม่ตรง (ขาด/เกิน) จะติดธงและถูกสอบถาม — นับให้ครบก่อนส่ง

## 7. บันทึกงานเสีย

ถ้างานของคุณพิมพ์เสีย/ตัดเสีย (เช่น ลูกค้าเปลี่ยนแบบหลังพิมพ์) บันทึกได้ที่ปุ่ม **งานเสีย**
ในใบงานของตัวเอง — ใส่เหตุผล วัสดุ และปริมาณที่เสีย เพื่อให้บัญชีวัสดุตรงกับความจริง

## คำถามที่พบบ่อย — ฝ่ายขาย

| ปัญหา | ทางแก้ |
|---|---|
| กรอกมัดจำ/ส่วนลดผิด | แจ้งฝ่ายการเงินหรือแอดมิน ปรับให้พร้อมเหตุผล |
| คอนเฟิร์มแบบผิดใบ | แจ้งแอดมิน (ย้อนสถานะเองไม่ได้) |
| ต้องการลบใบงาน | แจ้งแอดมิน (ฝ่ายขายลบเองไม่ได้) |
| มองไม่เห็นใบงานของเพื่อน | ปกติ — แต่ละคนเห็นเฉพาะงานตัวเอง |

# ฝ่ายกราฟิก (Graphic)

**หน้าที่:** รับงานออกแบบ → ส่งแบบให้ฝ่ายขายคอนเฟิร์ม → ส่งเข้าคิวผลิต
และ**พิมพ์งานเครื่อง FUJI (ตรายาง)** ด้วย

**เมนูที่ใช้ได้:** หน้าหลัก · โปรไฟล์ — หน้าหลักแสดง 2 กลุ่มงาน:
**คิวกลาง** (งาน "รอออกแบบ" ที่ยังไม่มีใครรับ — กราฟิกทุกคนเห็นเหมือนกัน) และ **งานของฉัน** (งานที่คุณกดรับแล้ว)

## 1. รับงานออกแบบ

1. ดูคิวกลางในหน้าหลัก — งานที่มีป้าย **ด่วน!** ให้รับก่อน และดูวันนัดรับงานประกอบ
2. เปิดใบงาน อ่านรายละเอียด (ประเภท ขนาด ตัวเลือก จำนวน) + รูปใบงาน + รูปอ้างอิงจากลูกค้า
3. กด **รับงานนี้** — งานเปลี่ยนเป็น "กำลังออกแบบ" และย้ายมาอยู่ในงานของฉัน

> รับแล้วงานเป็นของคุณ คนอื่นรับซ้ำไม่ได้ — ถ้ารับผิด งานล้นมือ หรือลาหยุด
> กดปุ่ม **🔄 ส่งต่องาน** ในใบงานเพื่อโอนให้กราฟิกคนอื่นได้เอง (ทำได้ขณะสถานะ "กำลังออกแบบ")

> บางงานฝ่ายขายจะกด **📨 ส่งให้กราฟิก** มอบหมายมาถึงคุณโดยตรงโดยไม่ผ่านคิวกลาง —
> งานแบบนี้โผล่ใน "งานของฉัน" ทันที

## 2. ออกแบบและส่งแบบ

1. ทำแบบตามสเปคในใบงาน — สงสัยอะไรถามฝ่ายขายผ่าน **คอมเมนต์** ในใบงาน
2. เปิดใบงาน → **แนบรูปแบบงาน (บังคับ)** — อัปโหลดรูปแบบที่เสร็จแล้ว
3. กด **ส่งแบบ** — งานเปลี่ยนเป็น "รอคอนเฟิร์มแบบ" ไปรอฝ่ายขายตรวจกับลูกค้า

## 3. ถ้าโดนขอแก้

ฝ่ายขายกด "ขอแก้" งานจะกลับมาเป็น **กำลังออกแบบ** ในมือคุณ
อ่านคอมเมนต์ว่าลูกค้าให้แก้ตรงไหน → แก้ → แนบรูปใหม่ → **ส่งแบบ** อีกครั้ง (วนได้จนกว่าจะผ่าน)

## 4. ส่งเข้าคิวผลิต

เมื่อฝ่ายขายคอนเฟิร์มแบบแล้ว (สถานะ **คอนเฟิร์มแล้ว**) หน้าที่สุดท้ายของคุณในงานออกแบบ:
กด **📦 ส่งเข้าผลิต** — ระบบจะแตกงานเป็นงานย่อยตามเครื่องพิมพ์ที่ต้องใช้ แล้วเข้าคิวฝ่ายผลิต

> อย่าลืมขั้นนี้ — งานที่ค้างสถานะ "คอนเฟิร์มแล้ว" คือแบบผ่านแล้วแต่ยังไม่เข้าคิวผลิต ลูกค้ารอฟรี

## 5. พิมพ์งานเครื่อง FUJI (งานตรายาง)

งานที่ใช้เครื่อง **FUJI** เป็นหน้าที่ทีมกราฟิก (ไม่ใช่ฝ่ายผลิต):

1. งาน FUJI ในคิวผลิตจะโผล่ให้ทีมกราฟิกเห็น — กด **รับงานนี้** ที่งานย่อยเครื่อง FUJI
2. พิมพ์งานจริง
3. เปิดใบงาน → **แนบรูปงานพิมพ์ (บังคับ)** + กรอก **บันทึกการพิมพ์**:
   วัสดุที่ใช้ หน้ากว้างม้วน ความยาวที่ใช้จริง (เมตร) และจำนวนที่พิมพ์จริง
4. บันทึกแล้วงานย่อย FUJI ถือว่าเสร็จ — เมื่อทุกเครื่องเสร็จ ใบงานจะเป็น "รอส่งมอบ"

> คนแนบรูป/บันทึกไม่จำเป็นต้องเป็นคนเดียวกับคนกดรับงาน — ขอแค่อยู่ทีมที่ดูแลเครื่องนั้น

> ⚠️ **กรอกความยาวที่ใช้จริงตามจริง** — ระบบคำนวณเปอร์เซ็นต์เศษวัสดุอัตโนมัติ
> ถ้าเศษสูงผิดปกติจะติดธงไปที่ฝ่ายการเงิน กรอกผิดแก้ได้ที่ปุ่ม **✏️ แก้บันทึก**
> (ต้องใส่เหตุผล — ระบบเก็บค่าก่อน/หลังแก้ลงประวัติเสมอ)

## 6. บันทึกงานเสีย

พิมพ์เสีย/เครื่องมีปัญหา/สีเพี้ยน → กด **งานเสีย** ในใบงาน บันทึกเหตุผล วัสดุ และปริมาณที่เสีย
บันทึกตรงตามจริง — ข้อมูลนี้ใช้ตามวัสดุที่หายไป ไม่ได้ใช้ลงโทษคนพิมพ์

## คำถามที่พบบ่อย — ฝ่ายกราฟิก

| ปัญหา | ทางแก้ |
|---|---|
| รับงานผิด / ทำต่อไม่ได้ | กดปุ่ม **🔄 ส่งต่องาน** โอนให้กราฟิกคนอื่นเอง (ขณะสถานะกำลังออกแบบ) |
| แบบผ่านแล้วแต่ลูกค้าเปลี่ยนใจ | ฝ่ายขายต้องแจ้งแอดมินย้อนสถานะ — คุณแก้เองไม่ได้ |
| กรอกบันทึกการพิมพ์ผิด | กด **✏️ แก้บันทึก** ในหัวข้อ "บันทึกการพิมพ์ที่บันทึกแล้ว" — ใส่เหตุผล ระบบลงประวัติให้ |
| ไม่เห็นเมนูสร้างใบงาน/รายงาน | ปกติ — เมนูเหล่านั้นเป็นของฝ่ายขาย/การเงิน |

# ฝ่ายผลิต (Production)

**หน้าที่:** รับงานพิมพ์ → พิมพ์ → แนบรูปงาน + บันทึกการพิมพ์และวัสดุ

**เมนูที่ใช้ได้:** หน้าหลัก · โปรไฟล์ — หน้าหลักแสดง:
**คิวกลาง** (งาน "คอนเฟิร์มแล้ว / รอผลิต" ที่ยังไม่มีใครรับ) และ **งานของฉัน** (งานที่คุณกดรับแล้ว)

## เครื่องที่ทีมผลิตดูแล

ใบงานหนึ่งใบอาจมีงานหลายเครื่อง ระบบแตกเป็น **งานย่อยต่อเครื่อง** ให้อัตโนมัติ:

| เครื่อง | ทีมที่ทำ |
|---|---|
| ไวนิล / สติกเกอร์ใหญ่ / สติกเกอร์ตัด / อื่นๆ | **ฝ่ายผลิต (คุณ)** |
| FUJI (ตรายาง) | ทีมกราฟิก |

แต่ละเครื่องรับงาน/ทำเสร็จแยกกันอิสระ — งานเครื่องคุณเสร็จแล้วไม่ต้องรอเครื่องอื่น
แต่ใบงานจะเป็น "รอส่งมอบ" ก็ต่อเมื่อ **ทุกเครื่องเสร็จครบ**

## 1. รับงานพิมพ์

1. ดูคิวกลาง — งานป้าย **ด่วน!** ทำก่อน และดู **วันนัดรับงาน** ประกอบการจัดคิว
2. เปิดใบงาน ดูรายละเอียด: ประเภท ขนาด ตัวเลือก (ตาไก่/พับขอบ) จำนวน + **รูปแบบที่คอนเฟิร์มแล้ว**
   (หัวข้อ "ฝ่ายกราฟิก > รูปที่ออกแบบ" — พิมพ์ตามแบบนี้เท่านั้น)
3. ที่หัวข้อ **งานพิมพ์แต่ละเครื่อง** กด **รับงานนี้** ตรงเครื่องที่คุณจะทำ

## 2. พิมพ์และบันทึกการพิมพ์

พิมพ์เสร็จแล้ว เปิดใบงานทำ 2 อย่าง (บังคับทั้งคู่):

**2.1 แนบรูปงานพิมพ์ (บังคับ)** — ถ่ายรูปงานที่พิมพ์จริง อัปโหลด

**2.2 กรอกบันทึกการพิมพ์** ต่อรายการงาน:

| ช่อง | กรอกอะไร |
|---|---|
| วัสดุ | เลือกจากรายการ (เช่น ดีรุยเซ่น หลังขาว, HP) |
| หลังขาว/ดำ/เทา | เฉพาะงานไวนิล |
| หน้ากว้างม้วน | เลือกตามม้วนที่ใช้จริง (เช่น 1.32 / 1.62 / 3.22 ม.) |
| ความยาวที่ใช้ (เมตร) | **วัดจากม้วนจริง รวมส่วนที่เผื่อ/เล็ม** — ไม่ใช่ขนาดชิ้นงาน |
| จำนวนพิมพ์จริง | ระบบใส่ให้เท่าจำนวนสั่ง แก้ได้ถ้าพิมพ์เผื่อ |
| พิมพ์รวมม้วน | ถ้าจัดวางหลายรายการพิมพ์บนม้วนเดียวกัน ให้ผูกเป็นชุดเดียวกัน — ระบบจะเฉลี่ยวัสดุให้ถูก |

บันทึกครบแล้วงานย่อยเครื่องนั้น = เสร็จ

> ⚠️ **กรอกตามจริงเสมอ** — ระบบคำนวณพื้นที่ที่ใช้ เทียบกับพื้นที่ที่ขาย
> ออกมาเป็นเปอร์เซ็นต์เศษวัสดุอัตโนมัติ ถ้าเกินเกณฑ์ (ประมาณ 30% เตือน / 50% ธงแดง)
> จะขึ้นรายงานที่ฝ่ายการเงิน — เศษเยอะเพราะงานชิ้นเล็กจัดวางไม่ลงตัวเป็นเรื่องปกติ อธิบายได้
> แต่ตัวเลขที่กรอกมั่วจะตรวจเจอตอนกระทบยอดม้วนวัสดุ

## 3. กรอกผิด แก้ยังไง

แก้ได้เองในใบงาน:

1. เปิดใบงาน → หัวข้อ **บันทึกการพิมพ์ที่บันทึกแล้ว**
2. กด **✏️ แก้บันทึก** ที่รายการที่ผิด → แก้วัสดุ/ม้วน/ความยาว/จำนวนให้ถูก
3. ใส่**เหตุผลที่แก้** (บังคับ เช่น "กรอกความยาวผิด วัดใหม่ได้ 4.2 ม.") → กด **💾 บันทึกการแก้**

- แก้ได้เฉพาะรายการของทีมเครื่องตัวเอง (งาน FUJI ทีมกราฟิกแก้ / เครื่องอื่นทีมผลิตแก้)
- ระบบเก็บค่าก่อน/หลังแก้ + เหตุผล ลงประวัติใบงานเสมอ — ชื่อผู้พิมพ์เดิมไม่เปลี่ยน
- เศษวัสดุคำนวณใหม่อัตโนมัติจากค่าที่แก้

## 4. บันทึกงานเสีย

พิมพ์เสีย ตัดเสีย เครื่องมีปัญหา สีเพี้ยน วัสดุมีตำหนิ → กด **งานเสีย** ในใบงาน:

1. เลือกเหตุผล (เลือก "อื่นๆ" ต้องพิมพ์รายละเอียด)
2. เลือกวัสดุ หน้ากว้างม้วน ความยาวที่เสีย จำนวนที่เสีย
3. บันทึก — แล้วพิมพ์ใหม่ + บันทึกการพิมพ์รอบใหม่ตามปกติ

การบันทึกงานเสียทำจาก**ในใบงาน**เท่านั้น — วัสดุที่เสียโดยไม่เกี่ยวกับใบงานไหนเลย
(เช่น ทดสอบเครื่อง เศษเปิดม้วน) ยังบันทึกในระบบไม่ได้ ให้จดแล้วแจ้งแอดมิน

> บันทึกงานเสียคือการบอกว่า "วัสดุหายไปไหน" — บันทึกตรงตามจริงช่วยคุณ
> เพราะถ้าไม่บันทึก วัสดุที่หายจะดูเหมือนเศษเกินของงานอื่นแทน

## คำถามที่พบบ่อย — ฝ่ายผลิต

| ปัญหา | ทางแก้ |
|---|---|
| รับงานผิดเครื่อง / ทำต่อไม่ได้ | แจ้งแอดมินย้ายงาน |
| วัสดุที่ใช้ไม่มีในรายการ | แจ้งแอดมินเพิ่มวัสดุในระบบ |
| งานเสร็จแล้วแต่ใบงานยังไม่เป็น "รอส่งมอบ" | เครื่องอื่นยังไม่เสร็จ — ดูที่ "งานพิมพ์แต่ละเครื่อง" |
| บันทึกงานเสียผิด | แจ้งแอดมินยกเลิกรายการให้ แล้วบันทึกใหม่ |

# ฝ่ายการเงิน (Finance)

**หน้าที่:** ตรวจสอบเงินทุกทาง — กระทบยอด อนุมัติคืนเงิน ตามลูกหนี้ ตรวจธงแดง

คุณ **อ่านข้อมูลได้ทั้งหมด** (ทุกใบงาน ทุกฝ่ายขาย) แต่ไม่ได้ทำงาน workflow
(ไม่สร้างใบงาน ไม่คอนเฟิร์มแบบ ไม่พิมพ์) — สิ่งเดียวที่แก้ได้คือ **ตัวเลขเงิน** พร้อมเหตุผลกำกับ

**เมนูที่ใช้ได้:** หน้าหลัก · งานทั้งหมด · สรุปงานรายวัน · **ตรวจเงิน** · โปรไฟล์
(**จ่ายรวม** ไม่อยู่ในเมนูข้าง — เข้าจากปุ่ม 💳 บนหน้าหลัก หรือลิงก์ "บันทึกจ่ายรวม" ในหน้าตรวจเงิน)

## หน้า "ตรวจเงิน" — งานหลักของคุณ

**ยอดรวมด้านบน:** ยอดขาย (เฉพาะงานส่งมอบแล้ว) · ยอดเงินสด · สัดส่วนเงินสด · จำนวนครั้งที่มีการเปลี่ยนยอดเงิน

### 1. งานติดธงแดง (ขายต่ำกว่าราคากลาง)

ระบบเทียบราคาขายจริงกับราคากลางอัตโนมัติทุกใบงาน — ตารางแสดงใบงาน ผู้ขาย
ราคากลาง ขายจริง ส่วนต่าง และระดับความรุนแรง
**สิ่งที่ต้องทำ:** ไล่ดูรายคน — ธงกระจุกที่ผู้ขายคนใดคนหนึ่งบ่อยผิดปกติ ให้สอบถามเหตุผลรายใบ

### 2. กระทบยอดเงินสดรายวัน

สิ้นวัน ฝ่ายขายแต่ละคนนับเงินสดมาส่ง:

1. เลือกผู้ขาย + วันที่ — ระบบแสดง **ยอดตามระบบ** (งานเงินสดที่ส่งมอบวันนั้น)
2. กรอก **ยอดที่นับได้จริง** → ระบบคำนวณส่วนต่าง
3. ส่วนต่าง ≠ 0 = ธงแดง — สอบถามผู้ขายก่อนปิด ใส่คำอธิบายในช่องหมายเหตุ
4. เรียบร้อยแล้วกด **ปิดรอบ** — ปิดแล้วแก้ไม่ได้

### 3. กระทบยอดโอน/เช็ค (เทียบ statement)

ตารางรวมรายการโอน/เช็คในระบบ (วันที่ วิธี เลขอ้างอิง ยอด งานที่ผูก)
เอาไว้ไล่เทียบกับ statement ธนาคารจริง — **เลขอ้างอิงซ้ำระบบจะติดธงให้** (สลิปใบเดียวใช้ซ้ำ)

### 4. คำขอคืนเงิน — อนุมัติ/ปฏิเสธ

ฝ่ายขายขอคืนเงินได้แต่คืนเองไม่ได้ ทุกคำขอมารอที่นี่:
ตรวจเหตุผล + ยอด (เกินยอดที่ลูกค้าจ่ายจริงไม่ได้) → **อนุมัติ** หรือ **ปฏิเสธ**

### 5. ลูกหนี้ค้างชำระ

งานที่ส่งมอบแล้วแต่ยังจ่ายไม่ครบ (ขายเครดิต) — ใช้ตามทวงถาม
งานปิดเมื่อยอดจ่ายจริง ≥ ยอดรับสุทธิ (งานที่โดนหัก ณ ที่จ่ายจะปิดได้ ไม่ค้างตลอดกาล)

### 6. ประวัติการเปลี่ยนยอดเงิน (audit)

ทุกการปรับยอดเงินโดยใครก็ตาม แสดง ก่อน→หลัง + คนทำ + เหตุผล — ไล่ดูความผิดปกติได้ที่นี่

### 7. รายงานเศษวัสดุ + กระทบยอดวัสดุ

- **รายงานเศษ (waste report)** — งานที่เศษวัสดุเกินเกณฑ์ (เตือน ~30% / ธงแดง ~50%) และงานเสียทั้งหมด
- **กระทบยอดวัสดุ (material reconcile)** — เทียบวัสดุที่ระบบบันทึกว่าใช้ กับม้วนจริงในสต็อก
- เศษสูงกระจุกที่คนพิมพ์คนเดียว/วัสดุตัวเดียว = จุดที่ควรเข้าไปดู

## การปรับยอดเงิน (adjust payment)

ฝ่ายขายกรอกส่วนลด/มัดจำ/วิธีจ่ายผิด → คุณปรับให้ได้ในใบงาน (ปุ่ม **ปรับยอดเงิน**):

- แก้ได้: ส่วนลด มัดจำ วิธีจ่าย วันจ่าย ค่าส่ง ค่าธรรมเนียม ค่าใช้จ่ายอื่นๆ VAT/หัก ณ ที่จ่าย
- แก้ไม่ได้: **ยอดรวม** — ระบบคำนวณจากรายการงานเสมอ (ต้องแก้รายการงาน = งานของแอดมิน)
- **ต้องใส่เหตุผลทุกครั้ง** ระบบบังคับ และลง audit อัตโนมัติ

## หลักที่ควรยึด

- ตัวเลขที่ระบบคำนวณ (ยอดรวม เศษวัสดุ ส่วนต่างเงินสด) เชื่อได้ — ระบบคำนวณฝั่งเซิร์ฟเวอร์ พนักงานพิมพ์ทับไม่ได้
- ธงแดงคือ "จุดที่ควรถาม" ไม่ใช่ "หลักฐานความผิด" — ถามก่อนสรุปเสมอ
- ทุกอย่างที่คุณทำ (อนุมัติ ปรับยอด ปิดรอบ) ก็ลง audit เช่นกัน

# ผู้ดูแลระบบ (Admin)

แอดมิน **ทำได้ทุกอย่างแทนทุกตำแหน่ง** + งานเฉพาะ: จัดการผู้ใช้ จัดการวัสดุ
ย้ายงาน ลบ/กู้คืนใบงาน และแก้กรณีที่พนักงานทำเองไม่ได้

**เมนูที่ใช้ได้:** ทุกเมนู รวมถึง **ตั้งค่า**
(**จ่ายรวม** ไม่อยู่ในเมนูข้าง — เข้าจากปุ่ม 💳 บนหน้าหลัก หรือลิงก์ในหน้าตรวจเงิน)

## 1. จัดการผู้ใช้ (ตั้งค่า > ผู้ใช้)

| งาน | วิธีทำ | หมายเหตุ |
|---|---|---|
| สร้างพนักงานใหม่ | กรอก username (ตัวพิมพ์เล็ก a-z 0-9 _), รหัสผ่าน, ชื่อที่แสดง, ตำแหน่ง | บอก username+รหัสให้พนักงานโดยตรง |
| เปลี่ยนตำแหน่ง | เลือกตำแหน่งใหม่ | พนักงานถูกบังคับ login ใหม่ทันที · **เปลี่ยนตำแหน่งตัวเองออกจาก admin ไม่ได้** |
| ปิดบัญชี (พนักงานลาออก) | ปิด "ใช้งาน" | ถูกดีดออกจากระบบทันทีทุกเครื่อง · **ปิดบัญชีตัวเองไม่ได้** — อย่าลบ ให้ปิดแทน ประวัติงานจะยังอยู่ |
| ตั้งรหัสผ่านใหม่ (ลืมรหัส) | Reset password | หลุดจากระบบทุกเครื่อง ต้อง login ใหม่ · ใช้เฉพาะกรณี**ลืมรหัส** — ถ้าแค่อยากเปลี่ยน พนักงานเปลี่ยนเองได้ที่หน้า**โปรไฟล์** (ต้องรู้รหัสปัจจุบัน) |

ตำแหน่งที่มี: **seller** (ฝ่ายขาย) · **graphic** (กราฟิก — รวมพิมพ์ FUJI) · **production** (ฝ่ายผลิต) ·
**finance** (การเงิน — อ่านได้หมด แก้ได้เฉพาะเงิน) · **admin**

> ให้ตำแหน่งตามหน้าที่จริงเท่านั้น — โดยเฉพาะ admin กับ finance ให้เท่าที่จำเป็น

## 2. จัดการราคากลาง (ตั้งค่า > ราคากลาง)

ราคากลางต่อประเภทงาน + ตัวเลือก (เช่น ไวนิล+ตาไก่) — ระบบใช้เทียบกับราคาขายจริง
ของฝ่ายขายอัตโนมัติ ถ้าขายต่ำกว่าเกณฑ์จะติดธงแดงที่หน้าตรวจเงิน

- เพิ่ม/แก้ด้วยปุ่ม **+ เพิ่มราคากลาง** ในหน้าตั้งค่า
- **อัปเดตทุกครั้งที่ต้นทุนหรือนโยบายราคาเปลี่ยน** — ราคากลางที่ล้าสมัยทำให้ธงแดงมั่ว
  (งานปกติโดนธง / งานกดราคาหลุดรอด) แล้วฝ่ายการเงินจะตรวจเพี้ยนทั้งระบบ
- ถ้ายังไม่เคยตั้งเลย มี seed script ให้ (`scripts/seed-rate-cards.ts` — งานฝั่งเทคนิค)

## 3. จัดการวัสดุ (ตั้งค่า > วัสดุ)

รายการวัสดุที่คนพิมพ์เลือกตอนบันทึกการพิมพ์:

- เพิ่ม/แก้: หมวด (ไวนิล/สติกเกอร์), ยี่ห้อ, ป้ายชื่อ, **หน้ากว้างม้วนที่มีจริง**, ต้นทุนต่อตารางเมตร (ถ้ารู้)
- วัสดุเลิกใช้ → ปิด active (หายจาก dropdown แต่ประวัติเก่ายังอยู่) — อย่าลบ
- หน้ากว้างม้วนต้องตรงกับม้วนที่ซื้อจริง ไม่งั้นคนพิมพ์เลือกไม่ได้/เลือกผิด แล้วตัวเลขเศษจะเพี้ยนทั้งระบบ

## 4. แก้งานแทนพนักงาน (กรณีที่พบบ่อย)

| พนักงานแจ้งว่า | สิ่งที่ต้องทำ |
|---|---|
| กราฟิก/คนพิมพ์รับงานผิดคน หรือลาป่วยงานค้าง | เปิดใบงาน → ย้ายงาน (reassign) ให้คนใหม่ · งานออกแบบที่ยัง "กำลังออกแบบ" กราฟิกใช้ปุ่ม **🔄 ส่งต่องาน** กันเองได้ ไม่ต้องผ่านคุณ |
| คนพิมพ์กรอกบันทึกการพิมพ์ผิด (วัสดุ/ความยาว) | ทีมเครื่องนั้นแก้เองได้ที่ปุ่ม **✏️ แก้บันทึก** ในใบงาน (แอดมินแก้ได้ทุกรายการ) — บังคับใส่เหตุผล ทุกการแก้ลง audit ก่อน/หลัง |
| ฝ่ายขายคอนเฟิร์มผิด / ลูกค้าเปลี่ยนใจหลังคอนเฟิร์ม | เปิดใบงาน → ปุ่ม **🔀 ปรับสถานะ (admin)** เลือกสถานะใหม่ + ใส่เหตุผล (บังคับ ลงประวัติเสมอ) — ข้ามขั้นได้ทุกสถานะ ใช้เท่าที่จำเป็น |
| ต้องแก้ใบงานหลังคอนเฟิร์ม (ขนาด/รายการ) | แอดมินแก้ได้ทุกสถานะ — แก้รายการงานแล้วยอดเงินคำนวณใหม่อัตโนมัติ |
| เปิดใบงานผิด ต้องลบ | ลบใบงาน (soft delete — กู้คืนได้ทีหลัง) |
| บันทึกงานเสียผิดรายการ | ยกเลิก (void) รายการงานเสียนั้น แล้วให้บันทึกใหม่ |
| กรอกยอดเงินผิด | ปรับยอดเงินในใบงาน (ใส่เหตุผล — ลง audit เสมอ) |
| วัสดุไม่มีใน dropdown | เพิ่มที่ ตั้งค่า > วัสดุ |

## 5. สิ่งที่ควรรู้เกี่ยวกับระบบ

- **ทุก action ลง audit** — รวมของแอดมินเอง ประวัติดูได้ท้ายใบงาน + หน้าตรวจเงิน
- **ยอดรวมเงินเป็นของระบบ** — คำนวณจากรายการงานฝั่งเซิร์ฟเวอร์เสมอ ไม่มีใครพิมพ์ทับได้ (รวมแอดมิน) ต้องการเปลี่ยนยอด = แก้รายการงานหรือส่วนลด
- **ลบ = ซ่อน** — ใบงานที่ลบกู้คืนได้ ไม่มีอะไรหายถาวรจากหน้าจอ
- ใบเสร็จลูกค้าเปิดผ่านลิงก์ QR ได้โดยไม่ต้อง login — เป็นหน้าสาธารณะที่ตั้งใจให้เป็นแบบนั้น
- เรื่องเชิงเทคนิค (deploy, schema, Cloud Functions) ดู `SCHEMA.md` และ `docs/` ในโปรเจกต์ — คู่มือชุดนี้สำหรับผู้ใช้งานเท่านั้น
