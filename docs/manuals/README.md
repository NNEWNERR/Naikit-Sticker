## สิ่งที่ทุกตำแหน่งต้องรู้

### การเข้าสู่ระบบ

1. เปิด https://naikit-sticker.web.app
2. กรอก **ชื่อผู้ใช้ (username)** และ **รหัสผ่าน** ที่ได้รับจากแอดมิน
3. เปลี่ยนรหัสผ่านเองได้ที่เมนู **โปรไฟล์** (ต้องกรอกรหัสปัจจุบัน รหัสใหม่ยาวอย่างน้อย 8 ตัว)
4. ถ้า**ลืม**รหัสผ่าน → แจ้งแอดมินให้ตั้งรหัสใหม่ให้ (หน้า login ไม่มีปุ่มลืมรหัสผ่าน)
5. ถ้าเข้าระบบไม่ได้ทั้งที่รหัสถูก อาจเป็นเพราะบัญชีถูกปิดใช้งาน → ติดต่อแอดมิน

### เมนูหลัก (เห็นเฉพาะเมนูที่ตำแหน่งของคุณใช้ได้)

| เมนู | ใครเห็น | ใช้ทำอะไร |
|---|---|---|
| 📋 หน้าหลัก | ทุกคน | คิวงานของตำแหน่งตัวเอง |
| ➕ สร้างใบงาน | ฝ่ายขาย, แอดมิน | เปิดใบงานใหม่ |
| 📊 งานทั้งหมด | ฝ่ายขาย, การเงิน, แอดมิน | ดูรายงานงานทั้งหมด |
| ✅ สรุปงานรายวัน | ฝ่ายขาย, การเงิน, แอดมิน | สรุปงานประจำวัน |
| 💰 ตรวจเงิน | การเงิน, แอดมิน | ตรวจสอบเงิน กระทบยอด |
| 👤 โปรไฟล์ | ทุกคน | ข้อมูลบัญชีตัวเอง + เปลี่ยนรหัสผ่าน |
| ⚙️ ตั้งค่า | แอดมิน | จัดการผู้ใช้ ราคากลาง และวัสดุ |

> **จ่ายรวม** (บันทึกจ่ายก้อนเดียวหลายใบงาน) ไม่อยู่ในเมนูข้าง —
> เป็นปุ่ม 💳 บนหน้าหลัก (ฝ่ายขาย/การเงิน/แอดมิน) และลิงก์ในหน้าตรวจเงิน

### สถานะของใบงาน (เรียงตามลำดับงาน)

```
รอออกแบบ → กำลังออกแบบ → รอคอนเฟิร์มแบบ → คอนเฟิร์มแล้ว
        → รอผลิต → กำลังผลิต → รอส่งมอบ → ส่งมอบแล้ว
```

| สถานะ | ความหมาย | ใครทำขั้นต่อไป |
|---|---|---|
| รอออกแบบ | เพิ่งเปิดใบงาน รอกราฟิกรับงาน | กราฟิกกด **รับงานนี้** |
| กำลังออกแบบ | กราฟิกกำลังทำแบบ | กราฟิกแนบรูปแบบ แล้วกด **ส่งแบบ** |
| รอคอนเฟิร์มแบบ | รอฝ่ายขายตรวจแบบกับลูกค้า | ฝ่ายขายกด **คอนเฟิร์ม** หรือ **ขอแก้** |
| คอนเฟิร์มแล้ว | ลูกค้าโอเคแบบแล้ว | กราฟิกกด **ส่งเข้าผลิต** |
| รอผลิต | อยู่ในคิวผลิต รอคนพิมพ์รับงาน | ฝ่ายผลิต (หรือกราฟิกถ้าเป็นงาน FUJI) กดรับงาน |
| กำลังผลิต | กำลังพิมพ์ | คนพิมพ์แนบรูปงาน + บันทึกการพิมพ์ |
| รอส่งมอบ | พิมพ์เสร็จทุกเครื่องแล้ว | ฝ่ายขายส่งลูกค้า แล้วกด **ส่งมอบ** |
| ส่งมอบแล้ว | ปิดงาน | — |

- ใบงานที่มีป้าย **ด่วน!** สีแดง = งานเร่ง ให้ทำก่อน
- งานที่มีหลายประเภท (เช่น ไวนิล + ตรายาง) จะแยกเป็นงานย่อยต่อเครื่อง —
  ต้องพิมพ์เสร็จ **ทุกเครื่อง** ใบงานถึงจะเป็น "รอส่งมอบ"

### คอมเมนต์ในใบงาน

ทุกใบงานมีช่องคอมเมนต์ด้านล่าง ใช้คุยกันข้ามฝ่ายเกี่ยวกับงานนั้น
(เช่น กราฟิกถามสเปค ฝ่ายขายแจ้งลูกค้าเปลี่ยนใจ) — ลบได้เฉพาะคอมเมนต์ของตัวเอง

### ข้อควรระวังทั่วไป

- **ทุกการกระทำถูกบันทึก** — ระบบเก็บประวัติว่าใครทำอะไรเมื่อไหร่ในทุกใบงาน
  (ดูได้ที่ "ประวัติการดำเนินการ" ท้ายใบงาน)
- **ตัวเลขเงินแก้เองไม่ได้หลังเปิดใบงาน** — ถ้ากรอกยอด/มัดจำ/ส่วนลดผิด
  ต้องแจ้งฝ่ายการเงินหรือแอดมินปรับให้ พร้อมบอกเหตุผล
- อย่าแชร์รหัสผ่านกับคนอื่น — งานที่ทำภายใต้บัญชีคุณถือว่าคุณเป็นคนทำ
